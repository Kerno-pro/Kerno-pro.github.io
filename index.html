THE QUESTIONS THAT MATTER

Private by default
should be easy to explain.

Can Kerno work without internet?

Yes. Once the models are on your device, chat, retrieval, and saved memory run locally. Network access is only needed for optional downloads and updates.

Where do my files and memories live?

They live in Kerno’s local app storage. Offline core chat has no cloud data path; you stay in control of what is added, kept, or removed.

Are model updates forced?

No. Updates are reviewed, signed, and opt in. Your current LLM or RAG model stays in place until you choose a new package.

Can I keep learning, life, and work separate?

Yes. Each assistant has its own sources, conversations, and optional memory, so one space never has to know about another.

Can I delete or export remembered conversations?

Memory controls are designed to stay visible: choose what is written, review it in the assistant knowledge base, then delete or export it when you need to.
